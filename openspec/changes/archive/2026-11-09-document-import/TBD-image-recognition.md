# TBD — 视觉模型图像识别（provider-based image recognition）

> 状态：**暂缓**。本文件记录"为什么现在不做、将来怎么接"，避免这个决定被忘掉或被悄悄降级实现。
> 相关：`design.md` D5 / D6，`specs/document-import/spec.md`（本地 OCR 已是承诺），`proposal.md`（Non-Goals）。

## 1. 现在做到哪一步

| 输入 | 现状 | 文本来源标记 |
|---|---|---|
| PDF 有文本层 | pymupdf 读文本层，带 `page` / `bbox` | `pdf_text` |
| PDF 扫描版 | pymupdf `get_textpage_ocr` 逐页 OCR | `image_ocr` |
| PNG / JPEG | pymupdf 直接打开为 1 页文档 + OCR，`bbox` 在图片坐标 | `image_ocr` |
| DOCX | 标准库 zip + XML 抽段落与表格 | `docx_text` |

本地 OCR 的已知短板：

- **拿不到逐词置信度**（pymupdf 不暴露 tesseract 的 conf），因此用"整类标待核实"表达不确定性，而不是给一个分数（见 `design.md` D6）。
- 中文金额、公司名、日期在低质量扫描件上容易错字；错字会被 `extract` 当成"文档里写的就是这样"。

## 2. 暂缓的是什么

**用视觉模型（多模态 LLM）替代或补强本地 OCR**，包括：

- 由模型直接"读图返回结构化结果"（字段值 + 位置 + 置信度）；
- 或由模型对本地 OCR 的结果做"校订"（同音字/形近字纠错）。

## 3. 为什么暂缓（不是懒，是三个具体风险）

1. **证据会自证。** 审计的 `provenance` 检查问的是"这个值能不能在它自己那个文件的全文里定位"。若全文来自模型转写，值当然能在模型自己的转写里找到——这条检查就失去了意义。本地 OCR 至少有图片坐标 `bbox`，指向的是**图片**那块区域。
2. **没有坐标就没有"待核实"的落点。** ED-04 要求给出页码/区域与置信提示。纯文本转写没有 bbox，UI 无法把"待核实"指回原文，用户只能通读全文。
3. **确定性与可复现性。** 同一张图两次调用可能给出不同文本；而"同一份输入应当得到同一份审计"（AT-01）是这个项目唯一不可让的承诺。导入发生在快照之前，理论上可容忍不确定性，但**必须在数据上标出来**，否则它会以"看起来确定的文本"进入快照。

## 4. 真要接的时候，需要先定的事

| 待定项 | 为什么必须先定 | 现状 |
|---|---|---|
| 真实 model id 与能力 | 需要确认该 endpoint **是否接受图片输入**（image content block）；文本模型无法 OCR | 未确认（提过 `deepseek-v4.1-flash-1017`，公开文档核不到该 id） |
| base URL 与 key 的环境变量 | 需要一个 `SMART_EDIT_OCR` 或复用 `SMART_EDIT_LLM` 的 scheme 约定 | 未定；`app/llm.py` 现有 `fixture:`，`openai:` 仍抛 `NotImplementedError` |
| 输出契约 | 必须返回 **block 级结构 + 坐标 + 置信度**，并逐条校验；否则不接受 | 未定 |
| 与本地 OCR 的关系 | 二选一还是"本地先跑、模型校订"？校订必须保留原 OCR 文本以便对照 | 未定 |
| 证据等级 | 模型产出的文本要不要引入 `form="image_model"` 一类新取值（**冻结契约，需签字**） | 未定 |

## 5. 触发条件（什么时候值得做）

满足其中一条再启动，避免"为了先进而先进"：

- 用真实样本实测本地 OCR：关键字段（金额 / 币种 / 起止日 / 交易对手）错识率超过业务可接受线；
- 出现本地引擎处理不了的版式（手写体、极低分辨率、复杂表格跨页）；
- 业务明确要求"图片→结构化字段"一步到位，并接受"待人工复核"的证据等级下降。

## 6. 明确不做的事

- **不**把模型转写文本当成"确定性结果"进入报告；
- **不**在没有坐标的情况下宣称"可回到原文"；
- **不**让导入路径的模型调用影响审计路径的零模型承诺（`app/rules/` 的 purity 测试继续守着）；
- **不**用"模型说这是 500000"覆盖用户已确认的值。

本 change 交付本地 OCR 主干；本文件是**已知缺口 + 已知计划**的记录。启动视觉模型识别应当是**独立 change**，并在其中回答第 4 节全部待定项。
