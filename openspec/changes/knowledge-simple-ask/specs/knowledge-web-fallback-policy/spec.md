# Spec Delta

## Purpose

定义知识问答的**联网兜底策略**：默认值由部署决定而非界面硬编码、用户始终可以显式关闭、每次运行都记录"有效选择与来源"、外呼前必须经过出站校验，并且联网结果必须被标注为未核验。

## ADDED Requirements

### Requirement: 联网兜底默认开启且必须可显式关闭

当法规证据不可用或本地语料没有可引用证据时，系统 SHALL 允许使用联网兜底；该兜底的**默认值 SHALL 由部署配置决定**（比赛环境默认开启），MUST NOT 由界面写死。用户 MUST 能在本次提问中显式关闭兜底，关闭后该次运行 MUST NOT 产生任何外部检索请求。

#### Scenario: 使用部署默认值

- **WHEN** 部署把兜底默认设为开启，且用户未做任何切换
- **THEN** 法规证据不可用时系统 MAY 发起联网检索
- **AND** 运行记录 MUST 标明该选择来自部署默认

#### Scenario: 用户显式关闭

- **WHEN** 用户关闭兜底后提问
- **THEN** 该次运行 MUST NOT 发起任何联网检索，即使法规证据不可用
- **AND** 回答 MUST 说明联网被关闭，而不是宣称"没有相关规定"

### Requirement: 每次运行必须记录有效选择与来源

系统 SHALL 为每次运行记录联网兜底的**有效取值**以及它的来源（用户选择或部署默认），MUST NOT 依赖事后推断。请求中 MUST 显式携带该取值，MUST NOT 依赖服务端隐式默认。

#### Scenario: 用户显式开启

- **WHEN** 用户开启兜底并提问
- **THEN** 运行请求 MUST 显式携带"允许联网"，且记录来源为用户选择

#### Scenario: 审计回溯

- **WHEN** 事后检查某次运行是否可能外呼
- **THEN** 仅凭运行记录 MUST 能回答"是否允许"与"由谁决定"

### Requirement: 外呼之前必须经过出站策略且失败即拒绝

任何联网检索 MUST 在发出请求之前经过出站策略校验；策略不可用、配置缺失或校验失败时，系统 MUST 拒绝外呼，MUST NOT 以"未脱敏就发送"或"跳过校验"的方式继续。

#### Scenario: 策略缺失

- **WHEN** 出站策略文件缺失或无法解析
- **THEN** 系统 MUST 拒绝发起联网检索
- **AND** 回答 MUST 说明联网被拦截，而不是静默降级

#### Scenario: 发生脱敏

- **WHEN** 出站策略对问题做了脱敏
- **THEN** 运行记录 MUST 保留脱敏原因
- **AND** 存储的原始问题 MUST 按既有规则标记为已脱敏

### Requirement: 联网结果必须标注为未核验

凡是来自联网的证据与结论，系统 MUST 明确标注为未核验的第三方内容，MUST NOT 以已核实来源、监管原文或法律意见的口吻呈现。

#### Scenario: 答案引用了联网结果

- **WHEN** 最终答案引用了联网证据
- **THEN** 引用 MUST 带有未核验标注与来源地址
- **AND** 答案 MUST NOT 声称该事实已被银行或监管机构核实

### Requirement: 敏感信息预设必须可配置且失败即拒绝

出站脱敏的预设（金额、单号、长数字、邮箱、链接、模板变量、自定义敏感词）SHALL 以配置文件提供，使非代码改动即可调整；但配置文件缺失、格式非法或**任一规则无法编译**时，系统 MUST 在启动阶段失败，MUST NOT 跳过该规则继续运行。规则条数与单条模式长度 MUST 有上限。

#### Scenario: 规则写得有误

- **WHEN** 配置中的某条脱敏规则不是合法正则
- **THEN** 系统 MUST 在启动阶段失败并指明该规则
- **AND** MUST NOT 以"少一条规则"的状态提供服务

#### Scenario: 规则数量或长度越界

- **WHEN** 配置超过允许的规则条数或单条模式长度
- **THEN** 系统 MUST 拒绝加载该配置

### Requirement: 规则编号豁免不可配置

"公开规则编号必须存活"这一豁免（例如 URDG/UCP/ISP/ISBP 及其编号）MUST 由代码固定，MUST NOT 由配置扩充或替换；配置化 MUST NOT 让金额、单号等敏感模式获得豁免。

#### Scenario: 配置试图扩充豁免

- **WHEN** 配置中出现任何试图新增豁免模式的字段
- **THEN** 系统 MUST 忽略或拒绝该字段
- **AND** 脱敏行为 MUST 与未配置时一致

#### Scenario: 脱敏吃到规则编号

- **WHEN** 某条脱敏规则误伤了问题中的规则编号
- **THEN** 系统 MUST 按既有逻辑把规则编号补回检索串
